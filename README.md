# 皮肤变化追踪（自用版）

照片存在你自己的 Google Drive，程序只读不改。全程免费额度内。
iPad 用浏览器打开即可，不用装 app。

---

## 它是怎么工作的

不是每次都把几十张原图重新比一遍——那样内存和时间都撑不住。

每张照片**只分析一次**，压成一组数字（7 个区域 × 5 个指标），存进一张 CSV。
之后「新照片 vs 全部历史」比较的是这些数字，不管你有 50 张还是 500 张，
都是秒出结果，内存里始终只有一张图。

**5 个指标**（全部是机械的像素统计）：

| 指标 | 含义 | 数值变大代表 |
|---|---|---|
| 粗糙度 | 毛孔/细纹尺度的纹理强度 | 纹理更明显 |
| 肤色不匀 | 区域内亮度的离散程度 | 肤色更不均 |
| 泛红度 | 该区域比全脸平均偏红多少 | 更红 |
| 斑点占比 | 明显暗于周围的小块的面积占比 | 斑点更多 |
| 反光度 | 高光像素占比 | 更油亮 |

判定用的是 **z 值**：这次的数值偏离你历史平均多少个标准差。
所以「改善/恶化」是相对你自己的常态说的，不是任何医学标准。

## 一次性设置（大约 15 分钟）

### 第 1 步：Drive 里建文件夹

1. drive.google.com → 新建文件夹，比如叫 `SkinPhotos`
2. 进入这个文件夹，**新建一个空的表格文件并命名为 `skin_metrics.csv`**
   （最简单的做法：电脑上建一个空的 txt，改名成 `skin_metrics.csv`，拖进去）

   ⚠️ 这一步不能省。服务账号自己没有存储配额，只能**更新**已存在的文件，
   不能新建文件。少了这个文件，分析结果就存不回云端。

3. 打开这个文件夹，看浏览器地址栏：
   `https://drive.google.com/drive/folders/1AbCdEf...` ← 最后那串就是**文件夹 ID**，记下来

### 第 2 步：建服务账号（免费）

1. console.cloud.google.com → 同意条款 → 新建项目（随便起名）
2. 左边菜单 →「API 和服务」→「已启用的 API」→ 搜 **Google Drive API** → 启用
3. 左边菜单 →「IAM 和管理」→「服务账号」→ 创建服务账号
   - 名称随便填，角色可以跳过，直接完成
4. 点进刚建的服务账号 →「密钥」标签 →「添加密钥」→「创建新密钥」→ 选 **JSON** → 下载
5. 复制这个服务账号的邮箱地址（长得像 `xxx@xxx.iam.gserviceaccount.com`）

### 第 3 步：把文件夹共享给服务账号

回到 Drive 的 `SkinPhotos` 文件夹 → 右键「共享」→ 把服务账号邮箱填进去 →
权限选 **编辑者** → 发送。

### 第 4 步：部署到 Streamlit Cloud（免费）

1. 把这 4 个文件传到一个 GitHub 仓库：
   `app.py` `skin_metrics.py` `drive_client.py` `requirements.txt`
2. share.streamlit.io → 用 GitHub 登录 → New app → 选你的仓库 → 主文件填 `app.py`
3. 部署前点 **Advanced settings → Secrets**，粘贴下面这段
   （把 JSON 密钥文件里的对应内容填进去）：

```toml
drive_folder_id = "你的文件夹ID"

[gcp_service_account]
type = "service_account"
project_id = "..."
private_key_id = "..."
private_key = "-----BEGIN PRIVATE KEY-----\n换行要写成\\n\n-----END PRIVATE KEY-----\n"
client_email = "xxx@xxx.iam.gserviceaccount.com"
client_id = "..."
auth_uri = "https://accounts.google.com/o/oauth2/auth"
token_uri = "https://oauth2.googleapis.com/token"
auth_provider_x509_cert_url = "https://www.googleapis.com/oauth2/v1/certs"
client_x509_cert_url = "..."
```

`private_key` 那行最容易出错：JSON 里的换行符本来就是 `\n`，
粘进 TOML 时保持原样（一整行、带 `\n`）就对了。

4. Deploy。第一次装 opencv 会慢一点，等两三分钟。

### 第 5 步：设成私密（重要）

app 部署好后 → Settings → Sharing → 改成只有指定邮箱能看，
把你自己的 Google 邮箱加进去。

**不设的话，链接是公开的。** 里面是你的脸的照片，务必设。

## 日常使用

1. iPad 上用 Google Drive app 把新照片传进 `SkinPhotos` 文件夹
2. 浏览器打开你的 Streamlit 链接
3. 左边点「扫描 Drive 并分析新照片」——只处理没见过的新照片，几秒钟
4. 三个标签页：
   - **最新 vs 历史**：这一张相比你过去所有照片，哪些区域哪些指标改善/恶化
   - **趋势曲线**：单项指标随时间的走势
   - **两张找茬**：挑任意两张，出热力图 + 差异红框

## 拍摄建议（直接决定数据有没有意义）

数值对光线、角度、表情极其敏感。程序做了亮度归一化和人脸对齐，
但补不了拍摄条件的巨大差异。建议：

- 固定位置、固定灯光（同一盏灯、同一时间段，避开窗边自然光）
- 素颜、洗完脸擦干后等 10 分钟再拍（刚洗完会泛红）
- 正脸、表情放松、不笑
- 同一部手机，关掉美颜和 HDR
- 建议每周一次就够了，天天拍看到的基本都是噪声

**HEIC 格式不支持**，iPhone 请到 设置 → 相机 → 格式 → 改成「兼容性最强」。

## 局限（先说清楚）

- 对齐靠的是人脸框裁剪 + 统一缩放，属于粗略对齐。歪头幅度大的照片会有明显误差。
- 「泛红度」是相对全脸平均的，不是绝对值——因为不同灯光下绝对色值没法比。
- 化妆、护肤品残留、刚运动完、生理期都会让数值大幅波动。
- Streamlit 免费版内存约 1GB，照片超过 300 张时首次全量分析可能需要分几次跑
  （已处理的会跳过，中断了再点一次就行）。
- **这个工具不评估、不诊断任何皮肤或健康状况。** 它只是把像素变化量化出来。
  皮肤上真正让你担心的变化，请找皮肤科医生。
